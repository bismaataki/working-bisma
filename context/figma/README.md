# figma/

Design references that are not shipped with the theme.

Put screenshots, token exports, and marked-up PDFs here while a feature is
in progress. Assets that must travel with the theme go in
`wp-content/themes/skaflow/assets/` and are referenced with
`get_theme_file_uri()`.

After a feature ships, put the useful mappings in `context/kb/` (colour,
type, component) and delete the dumps. This folder is empty between
features on purpose.

Live tokens: `wp-content/themes/skaflow/theme.json`.
Colour and type maps: `context/kb/design-token-color.md`,
`context/kb/design-token-typography.md`.
