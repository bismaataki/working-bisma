# plans/

Write a plan here before building a feature. One file per feature, named
`yyyy-mm-dd-slug.md`.

When the work lands, promote the stable facts into `context/kb/` or a rule,
write `implementation/<same-date>-<same-slug>.md`, append to
`context/CHANGELOG.md`, and then delete the plan. The implementation note is
the plan's permanent counterpart, so nothing is lost by deleting it. This
folder is empty between features on purpose.

Never leave a finished plan here as the only copy of a current fact.

Naming, front matter, and the close-out steps: the `sf-context-docs` skill.
